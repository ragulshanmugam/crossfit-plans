Superset — 5 rounds, alternating:

A) Bench Press · B) Pendlay Row. Do A, rest ~60 sec, do B, rest ~60–90 sec, repeat. Percentages are of your bench 1RM.

✓ Set A · Bench Press B · Pendlay Row Rest / Tempo
1 5 reps @ 70% 8 reps, moderate Rest 60s between A/B, 90s after B · 3 sec eccentric on bench
2 5 reps @ 75% 8 reps, +5 kg Rest 60s / 90s · 3 sec down, 1 sec pause on chest
3 5 reps @ 80% 8 reps, +5 kg Rest 60s / 2:00 · 2–3 sec eccentric, drive feet into floor
4 3 reps @ 85% 6 reps, heavy Rest 60s / 2:00–2:30 · control down, explode up
5 AMRAP @ 80% (stop 1 shy of failure) 6 reps, heavy Rest 2:00–2:30 after · smooth tempo, no bounce · use a spotter

Pendlay Row = every rep resets dead on the floor, torso parallel, no body English. Rows stay strict — the point is upper-back work, not another hinge.

🎯 Intended Stimulus

Heavy but crisp. Sets 1–4 should never feel like a grind — bar speed stays consistent. Set 5 is the only one that gets uncomfortable, and you still leave one rep in the tank. If bar speed dies on set 3, drop 5% and finish the remaining sets there.

Substitutions

  • No bench / no spotter → Barbell Floor Press (same sets/reps).
  • Cranky shoulder → Neutral-grip DB Bench Press, 8-8-8-6-AMRAP.
  • Low back sensitive → swap Pendlay Row for Chest-Supported DB Row, same reps.
